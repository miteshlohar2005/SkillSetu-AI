## 📖 Executive Summary

**SkillSetu AI** is an independent, commercial-grade AI platform engineered to revolutionize enterprise workforce development, continuous competency assessment, and career capacity building. Traditional Learning Management Systems (LMS) rely on passive video completions, static quizzes, and subjective annual reviews. SkillSetu AI replaces this with:

1. **Continuous Diagnostic Onboarding:** Mandatory intake evaluations that benchmark baseline skill proficiencies immediately upon registration.
2. **Standardized Multi-Domain Competency Frameworks:** Objective measurement across technical, analytical, regulatory, and leadership proficiencies.
3. **Dynamic Skill Gap Identification:** Real-time mathematical scoring that uncovers micro-deficits and prioritizes immediate interventions.
4. **Adaptive Curriculum Pathways:** AI-orchestrated training roadmaps tailored to the learner's cadre and performance history.
5. **Multi-Modal Assessment Modalities:** Document-to-MCQ generation, automated practicum evaluations, and speech-to-text oral viva examinations with realistic AI avatars.

## 🎨 ArtCraft Design System

SkillSetu AI adheres strictly to the **ArtCraft** design system: a stark, modern editorial system that balances utilitarian monochrome discipline with high-energy electric blue focal points.

### Color Tokens & Palette

| Token | Hex Value | Role & Usage |
| :--- | :---: | :--- |
| **Canvas Background** | `#F2F1EE` | Warm paper-toned neutral surface that eliminates harsh screen glare and provides editorial warmth |
| **Elevated Surface** | `#FFFFFF` | Crisp pure-white card surfaces, dialogs, drawers, and form modules |
| **Primary Charcoal** | `#101014` | High-contrast editorial text, structural card borders, primary action buttons |
| **Accent Electric Blue**| `#2D81FF` | Interactive links, active tab underlines, focus rings, progress bars, key metric highlights |
| **Structural Border** | `#E5E7EB` | Hairline dividing lines and card outlines replacing heavy, blurry shadows |
| **Alert / Error** | `#D64545` | Validation warnings, expired submission deadlines, and critical gap indicators |

### Typography Hierarchy

* **Headline Display:** `Archivo` (Semi-bold / 620 weight, negative letter spacing) — Used for prominent editorial hero headlines and section banners.
* **Prose & Navigation:** `Inter` (Regular / 400 & Semi-bold / 600 weight) — Used for body content, form labels, tooltips, and data tables.
* **Technical Metadata:** `Geist Mono` (Bold / 700 weight, uppercase tracking) — Used for numerical scores, timestamps, cadre tags, and code blocks.
* **Editorial Emphasis:** `Instrument Serif` (Regular / 400 weight, italicized) — Used sparingly for pull-quotes and mission statements.

### Geometry & Spacing Rhythm
* **Corner Radius:** Square 0px for inputs and primary buttons, minimal 4px radius for standard cards, and 8px for nested interactive pills.
* **Control Height:** Consistent 48px control height for input bars, select dropdowns, and primary buttons.
* **Elevation Principle:** Flat structural borders (`border border-[#E5E7EB]`) over heavy drop shadows.

## ⚡ Core Features & Capabilities

### 1. 📋 Mandatory Diagnostic Onboarding & Cadre Baseline Engine
* **Intake Guard:** New officers must complete a Diagnostic Assessment before advancing to general courses.
* **Cadre Presets with Zero-Downtime Guarantee:**
  - **Indian Statistical Service (ISS) Officer:** System of National Accounts (SNA 2008), Stratified Sampling (FSUs/SSUs), Consumer Price Index (CPI Modified Laspeyres formula), and National Quality Assurance Framework (NQAF).
  - **Subordinate Statistical Service (SSS) Officer:** Schedule scrutiny, household roster rules, multiplier inversion formulas ($N/n$), and Periodic Labour Force Survey (PLFS) usual status criteria.
  - **Field Operations Division (FOD) Investigator:** Urban Frame Survey (UFS) demarcation, CAPI tablet GPS geotagging, hamlet formation, and establishment registers.
* **Instant Provisioning:** Handled via `GET /api/quizzes/diagnostic` and `/interview?type=intake`.

### 2. 📊 4-Domain Competency Matrix
Continuous evaluation across four essential pillars:
* **Statistical Competencies:** Sampling Design, Variance Estimation, Multipliers, GDP & National Accounts, Price Indices, Demography.
* **Technical & Computational Rigor:** Official Statistical Computing (R, Python, STATA, SQL), CAPI data hygiene, Big Data pipelines.
* **Digital Governance & Policy:** Data Confidentiality, National Data Governance Standards, Open Data publishing, Ethical AI.
* **Managerial & Field Leadership:** Field logistics, Enumerator oversight, Quality control audits, Cross-functional operational delivery.

### 3. 🎯 Dynamic Skill Gap Analysis & Real-Time Scoring
* Synchronizes quiz submissions, practicum evaluations, and oral viva scores into standard mastery tiers:
  - **Expert (85–100%)**
  - **Advanced (70–84%)**
  - **Intermediate (55–69%)**
  - **Beginner (40–54%)**
  - **Novice (0–39%)**
* Quantifies gaps against designated benchmark cadre profiles with prioritized interventions.

### 4. 🗺️ Adaptive Learning Pathways
* Dynamically sequences micro-courses, practical modules, and structured competencies based on detected skill deficits.
* Tracks learning hours, milestone progress, and skill gap remediation.

### 5. 🎙️ Real-Time Voice Oral Viva Voce Engine
* Speech-to-text enabled simulated board examinations with interactive video avatars.
* Captures natural spoken responses, computes transcriptions, and generates immediate diagnostic rubrics with strengths, weaknesses, and model answers.

### 6. 📄 AI Document-to-MCQ Studio
* Allows instructors to upload reference manuals and circulars (PDF, DOCX, TXT).
* Parses content with extraction pipelines and synthesizes pedagogical 4-option MCQs with explanations and source citations.

### 7. 💬 SkillSetu Copilot AI
* Multi-turn conversational domain assistant trained on official statistical methodologies and administrative guidelines.
* Provides mathematical explanations, R/Python code snippets, and operational guidance in English and Hindi.

## ⚡ Installation & Local Setup Guide

### Prerequisites
* **Node.js**: v20.0.0 or higher (verified on Node v24.14.0)
* **npm**: v9.0.0 or higher
* **MongoDB**: Local MongoDB instance or MongoDB Atlas connection URI

### Step 1: Clone Repository
```bash
git clone https://github.com/suvojitmanna/SkillSetu-AI.git
cd SkillSetu-AI
```

### Step 2: Configure & Run Server
```bash
# Navigate to server directory
cd server

# Install backend dependencies
npm install

# Create environment file from template
cp .env.example .env
```

#### Server Environment Variables (`server/.env`)
```env
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:5173

# Database Connection (Atlas or Local)
MONGODB_URL=mongodb+srv://<username>:<password>@cluster.mongodb.net/skillsetu_ai?retryWrites=true&w=majority

# Authentication Security
JWT_SECRET=your_jwt_secret_key_change_in_production_min_32_chars

# AI Engine Credentials (Optional - Cadre presets active if unset)
GEMINI_API_KEY=your_gemini_api_key_here
GOOGLE_API_KEY=your_gemini_api_key_here
OPENROUTER_API_KEY=your_openrouter_api_key_here

# Mail Service for 2FA OTP (Optional - Console logging active if unset)
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your_email@domain.com
EMAIL_PASSWORD=your_app_password
EMAIL_FROM=noreply@skillsetu.ai
EMAIL_FROM_NAME="SkillSetu AI"
```

```bash
# Start backend server (runs on http://localhost:5000)
npm start
# Or start with nodemon development mode
npm run dev
```

### Step 3: Configure & Run Client
```bash
# Open a new terminal and navigate to client directory
cd ../client

# Install frontend dependencies
npm install

# Create environment file from template
cp .env.example .env
```

#### Client Environment Variables (`client/.env`)
```env
# Backend API server URL
VITE_BASE_URL=http://localhost:5000

# Google OAuth 2.0 Web Client ID (Optional)
# If left unset, the Google sign-in button provides clear setup instructions gracefully
VITE_GOOGLE_CLIENT_ID=your_google_oauth_client_id_here.apps.googleusercontent.com
```

```bash
# Start frontend development server (runs on http://localhost:5173)
npm run dev
```

Open your browser and navigate to **`http://localhost:5173`**.
